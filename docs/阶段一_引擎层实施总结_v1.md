## 一句话总结

把私教内核从 Streamlit 界面里**彻底拆出来**做成了干净的引擎层，并且**真正接进了一直被浪费的护城河**（65 节点 KG 判据 + 13 题型解题骨架）。现在 LLM 不再"裸奔自己猜"，而是站在 **标准解 + 评分点 + 一化儿讲法** 三根柱子上做事。诊断准确性这个头号难点，用"真题 rubric 客观校验 + LLM 真伪判定 + must_have 封顶"真正解决了——实测验证：学生说"转化率都升高"（错），系统准确判定并把 mastery 从 LLM 想给的 0.9 压到 0.6。

## 新建的架构（全部零界面依赖，可搬云端 App 后端）

```
ui    apps/stage1_demo.py（重写：只渲染，苹果化克制风格）
api   apps/api_server.py（FastAPI：HTTP↔引擎唯一翻译层，含 L1 图片上传）
engine core/tutor/
        session_orchestrator.py  编排（串起所有引擎）
        diagnose_engine.py       诊断（rubric 客观校验 + must_have 封顶）
        teach_engine.py          教学（标准解锚点 + 多讲法 + 反人机 + 恶性循环）
        task_machine.py          状态机（闸门 + 时间盒 + 动态重排）
        profile_model.py         两层学生模型（通用能力 + 学科能力）
        prompts.py               提示词（含反人机准则 + engagement/affect）
        llm_bridge.py            LLM 桥接
adapter adapters/retrieval/      检索 Port（本地BGE/云端/null 三实现）
        adapters/store/          存储 Port（本地JSON，云端Supabase待接）
data   core/data/knowledge_repository.py  读 65 KG 节点金矿
        core/data/item_repository.py       读真题库
        data/item_bank/*.jsonl             真题（含标准解+rubric）
        scripts/import_items.py            真题导入管线
```

## 关键机制（都已实测/测试验证）

| 机制 | 根治什么 | 验证 |
|---|---|---|
| **真题 rubric 客观校验 + LLM 真伪判定** | 诊断不准 | ✅ 实测：学生"转化率都升高"被准确判错 |
| **must_have 得分点封顶** | LLM 自报蒙混过关 | ✅ LLM 想给0.9，漏must_have被压到0.6 |
| **标准解锚点注入** | 讲解太表面 | ✅ 实测：AI精确锁定分母陷阱并讲透因果 |
| **多讲法策略库** | 卡住只会讲慢 | ✅ 逻辑→数值→类比→反例 换轨不重复 |
| **恶性循环检测** | 没懂→抛新题→又错 | ✅ 连错+抛新题→强制回最小概念 |
| **闸门用客观mastery** | 假装过关 | ✅ 客观没过LLM advance被拦截 |
| **时间盒不假装过关** | 硬讲完 | ✅ 时间到没过→记unfinished_gap |
| **反人机准则** | 黏腻人机感 | ✅ 写进system_prompt最高准则 |

测试：`tests/test_tutor_engine.py` 12/12 通过；旧 `test_private_tutor.py` 5/5 不破坏。

## 怎么跑

```bash
# 安装依赖（新增 fastapi）
pip install -r requirements.txt

# 1. Streamlit Demo（拿给同学测）
streamlit run apps/stage1_demo.py   # 端口 8502

# 2. FastAPI 后端（App 阶段复用同一接口）
uvicorn apps.api_server:app --port 8600
# 健康检查：curl http://127.0.0.1:8600/health

# 3. 跑测试
python3 tests/test_tutor_engine.py

# 4. 校验题库格式（Chris 搞到真题后导入用）
python3 scripts/import_items.py --validate
```

不填 API Key 走本地 fallback（零配置可跑）；填 Key 走真实 DeepSeek。
