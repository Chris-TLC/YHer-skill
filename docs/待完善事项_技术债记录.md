## 1. AI出题:依赖图的题型暂无法生成(2026-06-29 记录)

**问题**:出题器从真题学规律时,部分节点的真题本质依赖图(图像分析/晶胞结构/实验装置图/坐标曲线),AI是纯文本无法生成图,会产出"如图所示"但没有图的题,导致信息不完整、用户无法作答。

**现状(已做的最小处理)**:
- 已加**三道无图闸门**:①生成器prompt禁止出依赖图的题 ②代码层关键词硬拦截(IMG_KEYWORDS) ③对抗验证把"无图依赖"列为硬伤fail。
- 效果:新生成的题不再出现无图问题;但本质依赖图的节点(图像分析/晶胞计算等)会几乎全部被拦截、产不出题。

**影响**:约 5-8 个"纯图节点"目前无法贡献AI生成题:
- 化学平衡-工业应用与图像分析
- 晶体结构-晶胞计算与化学式
- (实验装置图、坐标曲线分析等类似节点)
- 这些恰恰是上海卷的重要题型,**若要让用户真正愿意付费,这块不能长期缺失**(Chris 强调)。

**待考虑方案(未来完善时再选)**:
- A. 给出题器配图能力:接文生图/化学结构图渲染(RDKit画分子、matplotlib画晶胞/曲线)→ AI出题时同时生成配图。
- B. 建一个"带图真题题库",这些节点不AI生成,直接从真题库抽(图是真题原图)。
- C. 多模态:让AI描述图,再用工具渲染成图。

**决策依据(Chris 2026-06-29)**:MVP优先,先把主流程跑通。纯文字节点(占绝大多数)已能产出高质量题,足够验证"AI内化真题出题"方案成立。图相关节点作为付费转化的重要补强,放到产品跑通后专项完善。

## 2. AI诊断题库:18个多步推理硬节点产不出题(2026-07-01)

**现象**:AI诊断题预生成跑了三轮(90→106→119/137),收敛后**仍有18个节点产不出题**,每轮新增递减(16→13→…),光重跑已无效。

**根因**:这18个全是上海卷**多步推理硬题/大题型**——有机推断与合成(5个)、滴定曲线、溶液三大守恒、盐类水解离子浓度、氧化还原计算、工艺流程、实验综合大题等。出题器生成时易留硬伤,对抗验证(挑刺→有硬伤即fail)卡得严,三次重生仍全军覆没。**越核心越难自动生成且通过质检**。

**实际影响(已缓解)**:靠「父节点聚合子节点AI题」(get_ai_questions 三层取题)+ KG兜底,18个里**15个诊断时仍能聚合到AI题**,体验不开天窗。
- **真正的硬空洞只有3个**(聚合到0道AI题,纯KG兜底):
  - 溶液三大守恒
  - 工艺流程
  - 实验综合大题

**决策(Chris 2026-07-01)**:**接受KG兜底,不再重跑**(三轮证明对这18个无效、纯烧钱)。AI诊断题库定格 **119/137(87%)** 收尾。3个硬空洞仍能用KG判据题诊断,只是题质略逊。

**待考虑方案(未来专项完善时再选)**:
- A. 为这3个(及其他难节点)**人工补几道金标准诊断题**入 gold_bank(build_progressive_questions 已支持 gold 优先,比AI生成更可靠)。
- B. 针对大题型**调出题prompt / 适当放宽这几个节点的对抗验证阈值**再试。
- C. 从真题库直接抽这些章节的原题作诊断题(不AI生成)。

**成本备忘**:三轮补题合计约 ¥6.25 + ¥4.36 ≈ **¥10.6**,无余额报错。
