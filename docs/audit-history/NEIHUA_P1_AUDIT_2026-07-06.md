## 四、失败模式排名（全部有已知解法）

1. **无选项 MCQ 29%** → `option_complete` 维度**已经存在于 qa_item_auditor**，生成管线没接。接上即灭。
2. 题面不适定 ~11% → 生成时 solver-in-the-loop（先让独立解答器答，答不出/多解/无匹配选项→重生成）。
3. 化学错误答案 6% → 判分模型交叉验证 + 家族级抽人审。
4. 格式不可用 5% → 题型白名单（本期禁结构简式题）。
5. 变式多样性塌缩（10_01=10_03=10_05 逐字相同；06 家族只换温度数字）→ 兄弟变式间 n-gram 互检（现有 gate 只对锚题查重）。
6. 独立解答通道弱（有机推断给空答案、无选项时自己脑补选项、08_04 推理写 0.8 结论选 A 自相矛盾）→ 解答器换强模型或双解答器取一致。
