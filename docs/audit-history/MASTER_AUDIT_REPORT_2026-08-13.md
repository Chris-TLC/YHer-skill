## 2. 数学 MVP 架构蓝图

### v0'（首月可交付，零数据可跑通闭环）

```
数据层：1732 保守筛查题 → 第一个 KC（选数值答案型：等差/等比数列求和，避开图题/过程题）
知识层：沪教版章节骨架 + 手工第一节点（1 个 KC + 前置边）
诊断层：固定 6 题蓝图（不自适应）；二元 Beta(1,1) 每答一题更新 P(master)
判分层：L0 文本归一 → L1 sympy parse → L2 题型化等价（第一版只做数值/根式/区间三类）
处方层：4 行规则（P(master)≥0.8 → 变式/复习视频；<0.8 → 概念视频+基础练习）
验证层：held-out 3 题早停→6（3/3=weak verified，否则扩 6 发 strong；禁 n=2 二值化）
画像层：本地事件源 JSONL（含 source 字段）+ per-KC {p̂, n, due}；due=FSRS-4.5 R=0.85 反解
界面层：四标签显示（掌握/前置/不稳/未知）由 p̂+前置 p̂+错误码规则推导，OLM scrutable
```

### v1（有真人数据后，按依赖顺序升级）

1. BKT G/S 拟合（Baker 2008 上下文估计；Cui 2012 指标验收）
2. EIG 选题 + P(top1)≥0.8–0.9 & min_length 4–5 变长停止
3. FSRS 个人化参数 + 阻尼；efficacy Beta-Binomial（只作平局键）
4. 前置先验接线（层级先验）、错误码路由、KG 扩展
5. 成熟期：题库校准后升 CD-CAT（Wang 2013）、DINA（每属性 4–6 题）

### 真人数据硬依赖（4 条，全部后置，闭环上线零阻塞）

1. G/S 拟合 2. CD-CAT 校准 3. FSRS 个人化 4. OLM 效果 A/B

## 3. 与前两轮审计的差异与修正

- **继承**：EIG 保留、题族/held-out 隔离、事件审计、fail-closed 治理、typed 判分、签字过滤。
- **加强**：gap>0.45 从"无依据"升为"立即废弃"（红队模拟发现四态早停误判 10.3% + gap 随时间自满足）；"P/U 不可辨识"从推测升为"12 题 4-way 上限 54–69%"的量化结论。
- **修正**：08-05 建议"FSRS 换默认参数"方向对但细节错（×3 其实≈4.5 自身，真缺陷是阻尼）；08-06 "直接证据门是主因"保持，但最小长度应从 3 升到 4–5 且按分类误判率模拟校准。
- **新增**：CBM 短探针文献线（为短验证辩护但禁止单会话二值化）；教育 OPE 专项（IPS/CAPE/隔离臂）；PIPL 本地优先架构论证；数学管线四层判分；v0'/v1 分阶段路线。

## 4. 未决问题（按阻塞程度）

1. **沪教版章节骨架的纸质核对**：上海考纲为二手来源，需对纸质教材目录核验（30 分钟内可完成，建议人工）。
2. **200 题 MFR 金标**：中文高考数学公式识别无现成基准，自建金标是数学线唯一新数据资产。
3. **第一个 KC 的确定**：v0' 建议"等差/等比数列求和"，需用户拍板（影响首批 6 题蓝图与视频绑定）。
4. **视频资源**：一数频道 900 万粉视频池尚未结构化到知识点（BV→KC 映射是推荐器前置）。
5. **错误码标注的人力预算**：NRM/mal-rule 半自动路线可行，但首批 KC 的 distractor 模式标注仍需 1–2 小时教师级投入。
6. **回访机制**：retained(d=7) 改为热身嵌入后，需要产品层设计"下次会话"触发（提醒渠道、家长/学生选择）。

## 5. 本轮审计自身的方法论限制

- Semantic Scholar/OpenAlex 全程 429，部分结论仅 Crossref/arXiv/ERIC 可达；中文文献（CNKI/万方/百度学术）不可达，中文教育测量传统（涂冬波团队 CD-CAT 等）仅元数据级证据。
- 全部模拟基于合成模型或现役常数；四态 61% vs 54–69% 的区间依赖常数假设，方向结论稳健、点值不精确。
- 未成年教育产品的中国实证（OLM 效果、留存）缺失，建议 MVP 内自测。
- 未覆盖：语音/多模态诊断（本项目无需求）、LLM 判分主链路（已被排除）、生成式出题（化学线已验证价值有限）。

## 6. 结论

现役化学引擎的 21 个组件中：**4 个保留、10 个改造、5 个替换、2 个降级**，无一需要推翻重来——这说明前代 AI 的设计骨架（贝叶斯推断 + 信息量选题 + 事件溯源 + fail-closed 治理）在文献上是站得住的，但**所有手设常数都未经过文献校准**，且四状态构念本身在短预算下不成立。数学 MVP 的最优架构不是"把化学引擎搬过来"，而是 v0' 的**降级版**（固定蓝图 + 二元 mastery + 规则处方 + 早停验证），把自适应、校准、bandit 全部推迟到有真人数据之后——这与前两轮审计"简单 baseline 优先"的方向一致，但本轮第一次给出了每个版本的具体参数和升级触发条件。
