## 一、八大招式核心解析

### 1. **root_cause_diagnosis**（根因诊断，100%覆盖）
- **核心**：不讲表面知识点，直击学生为什么错
- **体现**：每个知识点的`common_failures`都标注`cause`（根本原因）和`symptom`（表现症状）
- **应用**：诊断问题设计必须"一击即中"，学生一答就暴露思维漏洞
- **示例**：
  - 问："实验大题第一步必须圈出什么？"
  - 暴露：学生不圈实验目的 → 答题方向跑偏 → 把制备实验当成性质验证

### 2. **comparison_memory**（对比记忆，96.9%覆盖）
- **核心**：把易混淆的概念并排放，强制学生建立区分机制
- **体现**：Ksp vs 溶解度、水解 vs 电离、酸性氧化物 vs 不成盐氧化物
- **应用**：诊断时必问"XX和YY有什么区别？能只看A判断B吗？"
- **示例**：
  - 问："AgCl和Ag2CrO4，谁的溶解度大？为什么不能只看Ksp数字？"
  - 暴露：学生混淆Ksp大小与溶解度，不同类型电解质直接比数值

### 3. **fixed_procedure**（固定流程，95.4%覆盖）
- **核心**：把复杂问题变成"傻瓜式"操作清单
- **体现**：实验五步法（目的→原理→装置→操作→数据→误差）、离子方程式三步（拆→删→查）
- **应用**：讲解时必须给出"第一步做什么、第二步做什么"的清晰路径
- **示例**：
  - 实验大题：圈目的 → 找已知 → 看装置坑点 → 追踪元素 → 算倍率
  - 盖斯定律：写目标 → 找反应 → 正负翻倍 → 加减消去

### 4. **setter_perspective**（出题人视角，93.8%覆盖）
- **核心**：告诉学生"这道题是怎么挖坑的"
- **体现**：知识图谱中大量"命题人喜欢把XX省略""选项常设置YY陷阱"
- **应用**：讲题时必须拆解出题人意图，让学生从"做题者"变成"反命题"
- **示例**：
  - 问："装置图把加热仪器省略了，说明出题人想考你什么？"
  - 暴露：学生看不懂省略符号，写方程式忘加热条件

### 5. **keyword_screening**（关键词筛选，72.3%覆盖）
- **核心**：题目中的"已知""易水解""防倒吸"等词是送分信号
- **体现**：训练学生圈关键词 → 回头找已知 → 联想配套操作
- **应用**：验证学生答题时必问"题目哪句话告诉你要这么做？"
- **示例**：
  - 问："题目给的'已知'信息不用会变什么？"
  - 暴露：学生遇到干燥、温度控制问题没思路，卡住后不知道回头找已知

### 6. **dual_track**（双轨思维，56.9%覆盖）
- **核心**：同时追踪两条线（如元素去向、离子浓度守恒）
- **体现**：工艺流程追踪目标元素在固/液哪边，离子浓度同时看电荷+物料守恒
- **应用**：讲解时必须画"双线图"，让学生同步追踪
- **示例**：
  - 问："加硫酸酸浸后，二氧化硅和硫酸钙在溶液里还是渣里？"
  - 暴露：学生不会追踪元素，不知道每一步操作后目标在哪

### 7. **instant_judgment**（秒判能力，24.6%覆盖）
- **核心**：高频考点必须3秒内条件反射
- **体现**：看到"易水解"立刻想"防水""HCl气流"；看到"增加卤素"立刻想"先消去再加成"
- **应用**：训练时必须限时作答，建立"触发词→操作"的神经回路

### 8. **level_adaptation**（梯度适应，3.1%覆盖）
- **核心**：根据学生水平调整讲解深度（T1/T2/T3/T4）
- **体现**：基础学生只讲结论和口诀，冲刺学生讲原理和变式

## 二、诊断问题设计的5大核心特征

### 特征1：**一题暴露一个思维漏洞**
不问"会不会"，而是设计让学生"一答就露馅"的问题。

**示例**：
- ❌ 差的问法："你知道盐类水解吗？"
- ✅ 一化儿问法："碳酸氢根与偏铝酸根反应是双水解吗？产物有气体吗？"
  - 学生答"是双水解" → 暴露混淆水解与电离
  - 学生答"有CO2气体" → 暴露不理解酸式根电离

### 特征2：**问题必须关联"为什么错"的根因**
每个诊断问题都对应`common_failures`中的一个`cause`。

**示例**：
- 根因：学生没有"控制变量"意识
- 诊断："没有说等浓度的两种钠盐溶液，能只凭pH大小比较出对应酸的强弱吗？"
- 暴露：学生答"能" → 确认缺少变量控制意识

### 特征3：**问题设计逼学生"回头找线索"**
训练学生养成"卡住时回头看题干"的习惯。

**示例**：
- 问："题目说产物易水解，装置末端接干燥管是为了防什么？"
- 暴露：学生答不出 → 证明他没有联想"易水解→防水蒸气"

### 特征4：**用出题人视角设计陷阱题**
让学生体验"如果我是命题人，我会怎么挖坑"。

**示例**：
- 问："醋酸与氢氧化钠滴定至pH=7时，c(Na⁺)和c(CH3COO⁻)与c(H⁺)是同一个数量级吗？"
- 陷阱：学生看到"中性"就以为所有离子浓度相等

### 特征5：**3秒限时回答，建立条件反射**
高频考点必须快速判断，不能停下来推导。

**示例**：
- 问："要增加卤素原子数，是先消去还是先加成？3秒回答"
- 目的：强制学生建立"增加卤素→先消去再加成"的神经回路

## 三、视频推荐逻辑（智能匹配5要素）

根据知识图谱的`recommended_videos`字段分析，一化儿的视频推荐遵循：

### 1. **视频类型匹配学习场景**
| 学习场景 | 推荐视频类型 | 占比 |
|---------|------------|------|
| 预习新课 | `concept_intro`（概念入门） | 44% |
| 巩固复习 | `review_with_problems`（带题复习） | 31% |
| 考前冲刺 | `exam_problem_drill`（真题演练） | 24% |
| 知识突破 | `concept_intro` + `review_with_problems` | 混合 |
| 错题重做 | `exam_problem_drill`（针对性刷题） | 24% |

### 2. **难度匹配掌握度**
- 节点标记为"未掌握" → 推`T1/T2`难度的入门视频
- 节点标记为"部分掌握" → 推`T2/T3`难度的巩固视频
- 节点标记为"已掌握但考前强化" → 推`T3/T4`难度的压轴题视频

### 3. **地区优先级（上海特供）**
每个视频的`region_priority`字段标注适用地区：
- `["上海"]` → 优先推给上海学生
- `["全国"]` → 通用内容
- `["山东", "江苏"]` → 其他地区特供

**上海考情特征**（必须注入AI）：
- 实验题"更偏向实验探究与方案设计"，不是死板套路
- 常问"该步骤的目的是什么"，需用精炼化学用语作答
- 胶体制备题注重"能否搅拌、能否用自来水"等沪科版教材陷阱
- 盐类水解2-3年才考一次，不是高频点

### 4. **学习目标明确性**
每个视频都有`what_you_learn`和`completion_criterion`：
- `what_you_learn`：学完能干什么（写给学生看的）
- `completion_criterion`：怎么判断学会了（写给AI验证用的）

**示例**：
```json
{
  "what_you_learn": "系统学习化学定量型实验的基本原则、装置解读与误差分析",
  "completion_criterion": "能准确识别定量实验中的测量对象、装置作用及误差来源，独立完成基础定量实验题"
}
```

### 5. **视频时长与学习时段匹配**
- 1-2小时学习 → 推`duration_min < 60`的短视频（快速突破）
- 3-4小时学习 → 推`60 < duration_min < 120`的系统课（深度理解）
- 5-6小时学习 → 推多个视频组合（入门→巩固→刷题）

## 四、上海考纲的5大应试特征（必须注入AI）

### 1. **实验题偏"探究设计"而非"套路背诵"**
- 全国卷：装置连接、除杂干燥、尾气处理（固定套路）
- 上海卷：设计实验方案验证假设、解释步骤目的、控制变量思想
- **AI讲解时必须强调**："这道题不是背套路，是问你为什么要这么做"

### 2. **化学用语要求"精炼严谨"**
- 不能写"加热"，要写"水浴加热"或"油浴加热"
- 不能写"过滤"，要写"趁热过滤"或"冷却结晶后过滤"
- **AI验证答案时必须检查**：操作动词是否完整

### 3. **胶体制备是上海独有高频点**
- 全国卷很少单独考胶体
- 上海卷每年选择题或实验题必考"能否搅拌、能否用自来水"
- **AI推荐视频时**：上海学生必推胶体专题

### 4. **盐类水解不是高频点（2-3年一次）**
- 全国/山东/江苏：每年必考，选择+大题
- 上海：偶尔在工艺流程中提及，或作为FeCl3制备的背景知识
- **AI分配学习时间时**：上海学生不必在水解上花太多时间

### 5. **氮及其化合物考查较基础**
- 全国卷：硝酸氧化性、铵盐双水解等复杂应用
- 上海卷：氨气电子式、铵盐检验等基础操作
- **AI选题时**：上海学生少推T3/T4难度的氮化学综合题

## 六、与"模仿说话语气"的本质区别

| 维度 | ❌ 模仿说话语气 | ✅ 模仿教学思维 |
|------|--------------|--------------|
| 目标 | 让AI说话像杰哥 | 让AI教学像杰哥 |
| 体现 | "各位同学""我们来看""好家伙" | root_cause_diagnosis、fixed_procedure |
| 数据源 | 语料chunks的`text_preview` | 知识图谱的`common_failures`/`thinking_patterns_used` |
| 评价标准 | 学生觉得"挺像的" | 学生答对率提升、思维漏洞被修复 |
| 长期价值 | 新鲜感3天后消失 | 真正提升学习效率 |

**Chris的原话**：
> "不是模仿他的说话语气，而是模仿他的那种让同学更好理解的一些，教学上的那个思维的一个路径是知识点的路径，不是语说话的路径"

## 七、实战检验清单（AI自查用）

在每次讲解后，AI必须自检：

- [ ] 我有没有直击学生"为什么错"的根因？（root_cause_diagnosis）
- [ ] 我有没有对比类似的易混点？（comparison_memory）
- [ ] 我有没有给出"第一步、第二步"的固定流程？（fixed_procedure）
- [ ] 我有没有拆解出题人的挖坑意图？（setter_perspective）
- [ ] 我有没有提醒学生"题目哪句话是线索"？（keyword_screening）
- [ ] 我有没有同时追踪两条线（如元素去向）？（dual_track）
- [ ] 我有没有训练学生3秒秒判？（instant_judgment）
- [ ] 我推荐的视频是否匹配场景+难度+地区+时长？

**如果8条中有3条以上是"没有"，说明AI还在用通用chatbot的讲解方式，没有内化一化儿的教学思维。**
