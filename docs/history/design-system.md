# YHer 化学私教 · 前端设计规范(Design System)

> 基准实现:`apps/web/index.html`(Chris 2026-06-30 认可的风格)
> 用途:后续所有前端开发(补页面、做App、迭代)都遵循本规范,保持一致的"Apple 克制美学"。
> 最高准则(凌驾一切):**克制是最高级品味。判断标准是"用起来舒不舒服",不是"功能多不多"。**

---

## 一、设计基调

**Apple 克制美学**(Chris 反复强调,对标 Apple Store 购物页的精细度):
- 深色主题为底,大量留白
- 白色主按钮(强对比、克制)
- 18px 大圆角(卡片),14px 圆角(按钮/选项)
- **绝不用 emoji**
- **绝不显示模型名称**(DeepSeek/AI 字样不外露,只说"AI 私教")
- 动画:高级感、自然、丝滑——**不花里胡哨**,微动而非炫技
- 每个可点元素都要有反馈(hover 微动 + 点击缩放),营造"丝滑感"

---

## 二、色彩系统(CSS 变量)

```css
--bg:       #000      /* 页面纯黑底 */
--surface:  #1c1c1e   /* 卡片/控件底 */
--surface2: #2c2c2e   /* 次级面/悬停态 */
--line:     #38383a   /* 边框/分隔线 */
--text:     #f5f5f7   /* 主文字(近白) */
--text2:    #86868b   /* 次要文字(灰) */
--blue:     #0a84ff   /* 强调蓝(Apple 系统蓝) */
--green:    #30d158   /* 正确/掌握/成功 */
--amber:    #ff9f0a   /* 提醒/建议加强 */
--red:      #ff453a   /* 错误(克制使用) */
```

颜色语义固定:绿=对/掌握/提升,琥珀=建议加强,蓝=强调/可点,红=错(少用)。

---

## 三、圆角 / 间距 / 字体

| 元素 | 圆角 | 说明 |
|---|---|---|
| 卡片 card | 18px (`--radius`) | 主容器 |
| 按钮/选项/输入框 | 14px | 交互元素 |
| 小标签/进度点 | 10px / 圆形 | 状态指示 |

- 卡片内边距 22px,卡片间距 14px;页面最大宽度 **600px**(移动优先,居中)
- 字体栈:`-apple-system,"SF Pro Display","PingFang SC",system-ui`
- 字号:H1=34px/680字重,H2=24px/640,正文=15-17px,次要=13-14px
- 字间距:大标题 `letter-spacing:-.02em`(Apple 标题收紧感)
- 数字用 `font-variant-numeric:tabular-nums`(等宽对齐,雷达/百分比)

---

## 四、动效规范(核心:丝滑感)

**统一缓动曲线**:`cubic-bezier(.4,0,.2,1)`(变量 `--ease`,Apple 标准 ease-out)

| 交互 | 动效 | 时长 |
|---|---|---|
| 页面切换 | 淡入 + 上移 16px (`fadeUp`) | .55s |
| 卡片 hover | 上浮 3px + 边框提亮 + 阴影 | .35s |
| 卡片/按钮点击 | 缩放至 .97-.99 | .25s |
| 按钮 hover | 放大 1.015 | .25s |
| 选项选中 | 边框变蓝 + 底色微亮 | .28s |
| 雷达图出现 | 从中心 scale(.2)→1 + 淡入 | 1s |
| 能力条填充 | width 0→目标值 | 1.2s |
| 进度点切换 | 当前点放大 1.3 + 变色 | .4s |
| 加载 | 白色 spinner 旋转 | .8s/圈 |

**原则**:动画只用于"反馈"和"引导注意",不为动而动。粒子/庆祝效果要"微妙",宁可少。

| 组件 | class | 用途 |
|---|---|---|
| 卡片 | `.card` / `.card.tappable` | 容器,tappable 加 hover/点击动画 |

## 七、Wow Moment(产品惊喜点,定稿要求)

1. **能力雷达图**(首测后)— 从中心展开,"原来我的化学能力是这样"
2. **能力提升动画**(学后)— 数字滚动 28%→65%,进度条填充,"学习有效果"

动画要克制:能力值滚动 2s、进度条填充、**微妙**粒子——不要太花哨。

## 八、技术栈决策(Chris 2026-06-30 拍板)

- **前端**:原生 HTML/CSS/JS 单页应用(**不用 Streamlit**——它做不出丝滑动画/页面过渡,只能到 70% 苹果感)
- **后端**:复用现有 FastAPI(`apps/api_server.py`,端口 8600)
- 前后端分离,前端 fetch 调后端 HTTP 端点;CORS 已开
- App 阶段:同一套 FastAPI,前端换 Swift/SwiftUI(蓝图既定)

---

## 九、禁忌清单(踩了就是破坏风格)

- ❌ emoji
- ❌ 暴露"DeepSeek/GPT/模型"等字样
- ❌ 花哨渐变/炫光/过度动画
- ❌ 紧凑无留白的堆砌布局
- ❌ 生硬的直角/小圆角(必须 14-18px)
- ❌ 机械的"关心"文案(反人机准则,见 [[project-vision-blueprint]])
- ❌ Streamlit 那种"整页重渲染"的卡顿感
