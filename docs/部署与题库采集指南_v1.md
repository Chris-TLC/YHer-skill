## 第一部分：让国内同学能打开的网站（阿里云/腾讯云）

### 为什么要买云服务器
- `localhost` 只有你自己电脑能开。要让同学打开，需要一台有**公网 IP** 的服务器。
- Streamlit 官方免费云在国内经常打不开（被墙波动），不适合给国内同学。
- 国内云服务器（阿里/腾讯）国内访问稳定、快。

### 你要买什么（一次搞定）

**推荐配置（学生测试够用）：**
| 项 | 选择 | 说明 |
|---|---|---|
| 厂商 | 阿里云 或 腾讯云 | 学生有优惠，认证后更便宜 |
| 机型 | 轻量应用服务器 | 最简单，不用配网络 |
| 配置 | **2核4G 内存**起 | 4G 够跑（不加载本地BGE模型）；要跑BGE需8G |
| 系统 | **Ubuntu 22.04** | 最通用 |
| 带宽 | 3-5 Mbps | 测试够用 |
| 价格 | 学生机约 **¥60-100/月** | 阿里云/腾讯云学生认证有月付优惠 |

> ⚠️ 重要：**先不要买 8G/BGE 那种贵的**。阶段一引擎不强依赖本地 BGE（检索默认关），4G 就能跑，省钱。等真要上向量检索，用云向量服务（按量付费）比买大内存机器划算。

### 买完后的部署步骤（复制粘贴即可）

**1. 连上服务器**（云厂商控制台有"远程连接"按钮，或用 ssh）：
```bash
ssh root@你的服务器公网IP
```

**2. 装环境**：
```bash
apt update && apt install -y python3-pip git
```

**3. 传代码**（两种方式选一）：
```bash
# 方式A：如果你的代码在 GitHub
git clone https://github.com/Chris-TLC/YHer-skill.git
cd YHer-skill

# 方式B：用 scp 从本地传（在你自己电脑上跑）
# scp -r /Users/mac/Desktop/项目文件夹/Tools/yihuier-chemistry-skill root@你的IP:/root/yher
```

**4. 装依赖**：
```bash
pip3 install -r requirements.txt --break-system-packages
```

**5. 配 .env**：
```bash
cp .env.example .env
nano .env   # 填入 DEEPSEEK_API_KEY=sk-xxxx，保存（Ctrl+X, Y, 回车）
```

**6. 开放端口**：在云厂商控制台的"防火墙/安全组"里，放行 **8502**（前端）和 **8600**（后端）端口。这步在网页控制台点几下，不是命令行。

**7. 启动**：
```bash
bash deploy/start_server.sh
```

**8. 拿网址给同学**：
```
http://你的服务器公网IP:8502
```
这个网址国内同学就能直接打开了。

### 让它一直开着（关掉 ssh 也不停）
```bash
# 用 nohup 后台跑
nohup bash deploy/start_server.sh > run.log 2>&1 &
```

### 进阶（可选，以后做）
- **域名 + HTTPS**：买个域名指向 IP，配 nginx + 免费 SSL，网址更正规（`https://yher.xxx.com`）。备案问题：用国内服务器+域名需要 ICP 备案（约 2 周），不备案只能用 IP 访问。**测试阶段直接用 IP 就行，先不折腾备案。**

## 第二部分：把上海卷喂给 AI（题库采集）

### 决策已定：先只做上海
- 范围：上海近 3 年模拟卷（各区一二三模）+ 名校卷（四校八大）+ 近 10 年上海高考真题。
- 规模：~184 张卷 ≈ 3300 道题。
- 入库成本：**约 ¥59**（实测每题 ¥0.013）。
- 为什么先上海：工作量可控、卷子风格统一（rubric 质量高）、就是你的测试人群。做到 95 分再复制全国。

### Token 成本估算（已实测校准）

| 范围 | 卷数 | 题数 | 入库成本 |
|---|---|---|---|
| **只上海（推荐先做）** | ~184 | ~3300 | **¥59** |
| 全国全量（以后） | ~1470 | ~26000 | ¥473 |

> 关键认知：**入库是一次性的**。AI 解一遍题、提炼一次 rubric 存起来，之后运行时是检索已存结果，不重新解题。所以"恐怖的检索量"是误解——贵的是入库那一次，且 DeepSeek 极便宜。

### 好消息：你不用手动切题了，AI 自动切

原来要你手动把每道题整理成 JSON，现在有了 **AI 自动切题脚本** `scripts/split_papers.py`：直接读整张 docx/pdf 卷子 → AI 自动切成单题 + 对应答案 → 输出。你**几乎什么都不用整理**，把卷子文件夹喂进去就行。

**完整三步流程（卷子 → 可用题库）：**

```bash
# 第1步：AI 切题（读整张卷 → 切成单题对答案）
python3 scripts/split_papers.py --dir "/path/to/上海化学卷合集/05.2008-2026·（上海）化学高考真题" --out shanghai_gaokao
#   → 输出 data/raw_papers/shanghai_gaokao.jsonl

# 第2步：AI 入库（解题 + 提炼rubric + 挂KG/题型/视频）
python3 scripts/process_papers.py --input data/raw_papers/shanghai_gaokao.jsonl --topic shanghai_gaokao
#   → 输出 data/item_bank/shanghai_gaokao.jsonl，引擎立刻能用

# 第3步：校验
python3 scripts/import_items.py --validate
```

建议先小批量试，确认质量：
```bash
python3 scripts/split_papers.py --dir "xxx文件夹" --out test --limit 2   # 先切2张
python3 scripts/process_papers.py --input data/raw_papers/test.jsonl --topic test --limit 5
```

**实测效果**：一张 2026 上海高考真题，AI 准确切出 29 道题（题号/题干/选项/答案全对），切题 ¥0.11/卷，入库 ¥0.013/题。

### ⚠️ 公式图片问题 + 视觉方案（重要）

**实测发现**：上海化学卷平均每卷 **112 个图片对象**——方程式、结构式、装置图、坐标图几乎全是贴图，不是文字。纯文本提取会丢失 **一半以上** 的题内容。这是必须解决的大问题。

**两条切题路线，按需选：**

| 路线 | 脚本 | 成本/卷 | 公式图 | 适用 |
|---|---|---|---|---|
| 纯文本切题 | `split_papers.py` | ¥0.1 | ❌ 丢失 | 概念题/纯文字题 |
| **视觉切题（根治）** | `split_papers_vision.py` | ¥0.15 | ✅ 读得出 | 公式/装置图重的题 |

**视觉切题流程**（推荐主用，公式装置图能读出）：
```bash
# 1. 先开通一个视觉模型 key（推荐通义 qwen-vl，国内快便宜）
#    去 https://dashscope.console.aliyun.com/apiKey 开通
#    填进 .env：DASHSCOPE_API_KEY=sk-xxxx
# 2. 视觉切题（自动把卷子每页转图→视觉模型读出方程式装置图→切题）
python3 scripts/split_papers_vision.py --dir "上海化学卷合集/05.2008-2026..." --out shanghai_gaokao --vision qwen-vl
# 3. 入库（同纯文本路线）
python3 scripts/process_papers.py --input data/raw_papers/shanghai_gaokao.jsonl --topic shanghai_gaokao
```

**视觉成本（实测渲染清晰，公式结构式都看得清）**：
- 单页 ¥0.018，单卷(~8页) ¥0.15
- **上海全量 237 份视觉切题约 ¥35**；先做高考真题 40 份约 ¥6
- 比纯文本贵一点，但换来公式/装置图能读出，值得

**注意**：
- PDF 卷子直接能转图（零依赖）。**docx 转图需要装 LibreOffice**：`brew install --cask libreoffice`（一次性）。
- 视觉模型 key 要单独开通（DeepSeek 没有视觉模型）。推荐通义 qwen-vl 或豆包 vision，国内便宜。
- 优先用"解析版/含答案"卷（脚本自动选），题和答案在一起切得最准。

### 简单策略建议
- **公式重的卷（高考真题、结构化学、有机推断、实验题）→ 用视觉切题**
- **纯文字概念题 → 用文本切题（更便宜）**
- 不确定就全用视觉，反正 237 份才 ¥35。

### （旧方式，可选）手动整理格式
如果某些卷子 AI 切不好，也可以手动整理成 `data/raw_papers/_模板示例.jsonl` 的格式，再跑第2步入库。

### 喂给 AI（手动整理的话）

```bash
# 先小批量测试（前3题，看质量对不对）
python3 scripts/process_papers.py --input data/raw_papers/上海2024.jsonl --topic shanghai_2024 --limit 3

# 没问题就全量跑
python3 scripts/process_papers.py --input data/raw_papers/上海2024.jsonl --topic shanghai_2024

# 校验入库格式
python3 scripts/import_items.py --validate
```

AI 会对每道题：①自己解一遍理解内核 ②提炼得分点rubric ③挂到知识图谱和题型 ④挂引流视频。处理完自动进 `data/item_bank/`，引擎立刻能用。

### 实测样例（证明质量）
一道上海风格化学平衡题，AI 处理后：
- 准确挂到「化学平衡」「平衡常数」节点 + 「选择题-反应速率与平衡」题型
- 解题思路精确抓住内核："转化率变化需同时考虑分子和分母，不能简单套用平衡移动方向"
- 3 个得分点全标 must_have、配精准关键词
- 自动挂出题人陷阱 + 引流视频
- 成本 ¥0.013
