## 第一部分：让国内同学能打开的网站（阿里云/腾讯云）

### 为什么要买云服务器
- `localhost` 只有你自己电脑能开。要让同学打开，需要一台有**公网 IP** 的服务器。
- Streamlit 官方免费云在国内经常打不开（被墙波动），不适合给国内同学。
- 国内云服务器（阿里/腾讯）国内访问稳定、快。

### 你要买什么（一次搞定）

**推荐配置（学生测试够用）：**
| 项 | 选择 | 说明 |
|---|---|---|
| 厂商 | 阿里云 或 腾讯云 | 学生有优惠，认证后更便宜 |
| 机型 | 轻量应用服务器 | 最简单，不用配网络 |
| 配置 | **2核4G 内存**起 | 4G 够跑（不加载本地BGE模型）；要跑BGE需8G |
| 系统 | **Ubuntu 22.04** | 最通用 |
| 带宽 | 3-5 Mbps | 测试够用 |
| 价格 | 学生机约 **¥60-100/月** | 阿里云/腾讯云学生认证有月付优惠 |

> ⚠️ 重要：**先不要买 8G/BGE 那种贵的**。阶段一引擎不强依赖本地 BGE（检索默认关），4G 就能跑，省钱。等真要上向量检索，用云向量服务（按量付费）比买大内存机器划算。

### 买完后的部署步骤（复制粘贴即可）

**1. 连上服务器**（云厂商控制台有"远程连接"按钮，或用 ssh）：
```bash
ssh root@你的服务器公网IP
```

**2. 装环境**：
```bash
apt update && apt install -y python3-pip git
```

**3. 传代码**（两种方式选一）：
```bash
# 方式A：如果你的代码在 GitHub
git clone https://github.com/Chris-TLC/YHer-skill.git
cd YHer-skill

# 方式B：用 scp 从本地传（在你自己电脑上跑）
# scp -r /Users/mac/Desktop/项目文件夹/Tools/yihuier-chemistry-skill root@你的IP:/root/yher
```

**4. 装依赖**：
```bash
pip3 install -r requirements.txt --break-system-packages
```

**5. 配 .env**：
```bash
cp .env.example .env
nano .env   # 填入 DEEPSEEK_API_KEY=sk-xxxx，保存（Ctrl+X, Y, 回车）
```

**6. 开放端口**：在云厂商控制台的"防火墙/安全组"里，放行 **8502**（前端）和 **8600**（后端）端口。这步在网页控制台点几下，不是命令行。

**7. 启动**：
```bash
bash deploy/start_server.sh
```

**8. 拿网址给同学**：
```
http://你的服务器公网IP:8502
```
这个网址国内同学就能直接打开了。

### 让它一直开着（关掉 ssh 也不停）
```bash
# 用 nohup 后台跑
nohup bash deploy/start_server.sh > run.log 2>&1 &
```

### 进阶（可选，以后做）
- **域名 + HTTPS**：买个域名指向 IP，配 nginx + 免费 SSL，网址更正规（`https://yher.xxx.com`）。备案问题：用国内服务器+域名需要 ICP 备案（约 2 周），不备案只能用 IP 访问。**测试阶段直接用 IP 就行，先不折腾备案。**

## 第二部分：把上海卷喂给 AI（题库采集）

### 决策已定：先只做上海
- 范围：上海近 3 年模拟卷（各区一二三模）+ 名校卷（四校八大）+ 近 10 年上海高考真题。
- 规模：~184 张卷 ≈ 3300 道题。
- 入库成本：**约 ¥59**（实测每题 ¥0.013）。
- 为什么先上海：工作量可控、卷子风格统一（rubric 质量高）、就是你的测试人群。做到 95 分再复制全国。

### Token 成本估算（已实测校准）

| 范围 | 卷数 | 题数 | 入库成本 |
|---|---|---|---|
| **只上海（推荐先做）** | ~184 | ~3300 | **¥59** |
| 全国全量（以后） | ~1470 | ~26000 | ¥473 |

> 关键认知：**入库是一次性的**。AI 解一遍题、提炼一次 rubric 存起来，之后运行时是检索已存结果，不重新解题。所以"恐怖的检索量"是误解——贵的是入库那一次，且 DeepSeek 极便宜。

### 你要做的：把卷子整理成这个格式

每道题整理成一行 JSON，放进 `data/raw_papers/上海2024.jsonl`（参考 `data/raw_papers/_模板示例.jsonl`）：

```json
{"source":"2024上海普陀一模T19","region":"上海卷","year":2024,"stem":"题干（化学式纯文本如N2+3H2⇌2NH3，图表用文字描述）","sub_questions":[{"sub_id":"(1)","stem":"小问","answer":"标准答案（照抄卷子后面的答案）","score":4}]}
```

**每题你要填 5 样**（缺一不可）：
1. `source` 来源（哪年哪区第几题）
2. `stem` 题干（化学式用纯文本，图表用文字描述）
3. `sub_questions` 每小问的题 + **标准答案** + 分值
4. （没拆小问的题：整题放 stem，整体答案放 `raw_answer`）

> rubric 得分点、KG 挂接、出题人陷阱、引流视频——**这些 AI 自动生成，你不用填**。你只要把"题干+答案+分值"整理对。

### 整理卷子的省力建议
- 卷子和答案常常分开，你要做的核心工作就是**把答案对应到每道题**。
- 题干里的图、表、装置图：用**文字描述**（如"装置图：左接锥形瓶，右接集气瓶"）。手写/图片识别是 App 阶段的事，现在先文字化。
- 化学式：用纯文本，下标直接写（H2SO4、SO4^2-、N2+3H2⇌2NH3）。

### 喂给 AI（你整理好后跑这个）

```bash
# 先小批量测试（前3题，看质量对不对）
python3 scripts/process_papers.py --input data/raw_papers/上海2024.jsonl --topic shanghai_2024 --limit 3

# 没问题就全量跑
python3 scripts/process_papers.py --input data/raw_papers/上海2024.jsonl --topic shanghai_2024

# 校验入库格式
python3 scripts/import_items.py --validate
```

AI 会对每道题：①自己解一遍理解内核 ②提炼得分点rubric ③挂到知识图谱和题型 ④挂引流视频。处理完自动进 `data/item_bank/`，引擎立刻能用。

### 实测样例（证明质量）
一道上海风格化学平衡题，AI 处理后：
- 准确挂到「化学平衡」「平衡常数」节点 + 「选择题-反应速率与平衡」题型
- 解题思路精确抓住内核："转化率变化需同时考虑分子和分母，不能简单套用平衡移动方向"
- 3 个得分点全标 must_have、配精准关键词
- 自动挂出题人陷阱 + 引流视频
- 成本 ¥0.013
